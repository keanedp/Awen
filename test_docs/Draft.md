#### A calm place to write

Awen is a **focused Markdown editor** for macOS and Windows. It's just you, your words and a clean column of text. No toolbars, no accounts, no cloud. Your writing stays in plain `.md` files that you own and that open *anywhere*.

> The Markdown fades into the background, so the page reads like prose. Press ⌘R to see it rendered, then press it again to get straight back to writing.

## Code blocks, too
```clojure
(defn write [idea]
  (-> idea draft revise publish))
```
